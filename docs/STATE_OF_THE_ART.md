# State of the art

This page restates initial research and conceptual work by Yahya (`yahyabmo`), supplied for this project. It is a historical research summary, not an independent or current verification of the named products, their features, licenses, or policies. Those claims need source checks before they guide implementation or public comparisons.

| Category | Examples identified in the initial research | Reported opportunity |
| --- | --- | --- |
| Scientific simulation collections | PhET, myPhysicsLab, Falstad, Complexity Explorables | Rich scientific experiences; limited paths for external publishing were reported. |
| Technology-specific contribution platforms | Wolfram Demonstrations, Shadertoy, OpenProcessing, NetLogo | Contributor workflows exist, but each centers on a particular technology or environment. |
| General interactive code platforms | Observable, CodePen, JSFiddle, Hugging Face Spaces | Flexible publishing, without a shared scientific reference structure as their primary organizing model. |

The proposed SimuBox niche is a structured scientific catalogue with explanations, source access, and a route for browser-compatible simulations from different technologies. This differentiation is a hypothesis. Discovery work should verify the comparisons and test whether users and contributors value that combination.
